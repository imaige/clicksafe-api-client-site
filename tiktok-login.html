Authorize the sandbox target account

This page starts TikTok's official Web Login Kit OAuth flow. The TikTok Client Secret is never used or stored in this browser page.

Enter the Sandbox Client key from TikTok Developer Portal. It is used only to build the TikTok authorization URL for this browser session and is not written to this site.

Requested scopes: user.info.basic,video.publish

Registered callback: https://imaige.github.io/clicksafe-api-client-site/tiktok-callback.html

Security notes

  • A cryptographically random OAuth state value is generated for each authorization attempt.
  • The state value is kept only in this browser session and is verified by the registered callback.
  • Authorization-code exchange and all Client Secret handling occur only in the secure server-side GitHub Actions flow.
  • No TikTok access token or refresh token is displayed by this page.

ClickSafe Content Agent is an independent API client and is not endorsed by TikTok.
