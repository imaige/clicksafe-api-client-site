Scope

ClickSafe Content Agent is a personal API client used by the owner of the ClickSafe Daily YouTube channel. It uses YouTube API Services and YouTube Analytics API data only for the authorized channel-management and content-production purposes described here.

Google and YouTube data accessed

After Google OAuth authorization, the client may access:

  • authorized YouTube channel identity, including channel ID and channel title;
  • video IDs, titles, descriptions, status/visibility and related upload metadata needed to upload or verify content;
  • channel/video analytics used by the client, such as views, estimated watch time, average view duration, average viewed percentage, likes, comments, shares and subscriber gains/losses;
  • OAuth authorization tokens required to perform the owner-authorized API operations.

The client does not request, collect, or store the user's Google or YouTube password.

How data is used

  • Confirm that API operations target the authorized ClickSafe Daily channel.
  • Upload and verify owner-authorized video content and metadata.
  • Measure performance and choose future topics from an owner-approved content plan.
  • Maintain limited operational history needed to prevent duplicate releases and audit automation behavior.

Authorized YouTube API data is not sold. The client does not use YouTube API data for advertising or user profiling.

Storage and security

OAuth credentials are stored as a protected GitHub Actions secret rather than in the source repository. Operational artifacts are minimized and configured for short retention. Repository access is restricted to the project owner and explicitly authorized tooling. Transport to Google/YouTube APIs uses HTTPS.

Third parties

The client communicates with Google/YouTube to provide YouTube API functionality. Google processes information under the Google Privacy Policy. The content-production pipeline may separately use external generation or media services for non-YouTube production inputs; YouTube-authorized account data is not intentionally sent to those services for advertising or profiling.

Revocation and deletion

The owner can revoke the client's Google authorization from the Google Account permissions/security controls. After revocation, the OAuth secret can be deleted from GitHub Actions and locally generated token files can be deleted. Stored analytics snapshots, audit artifacts, and topic/history records derived for this client can also be deleted from the repository or Actions artifacts when no longer required.

If this client is ever made available to additional users, a clear request channel for deletion of their personal data will be provided before such access is enabled.

Consent and control

YouTube write actions and visibility changes are performed only within the scope configured and expressly authorized by the channel owner. The automation can be disabled and authorization can be revoked at any time.
